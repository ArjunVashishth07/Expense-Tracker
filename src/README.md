# Expense Tracker

A simple Java Full Stack Expense Tracker application built using Spring Boot. This project helps users manage and track daily expenses with a clean and responsive interface.

---

## Features

- Add new expenses
- View all expenses
- Delete expenses
- Responsive frontend UI
- REST API integration
- Backend built using Spring Boot

---

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- Maven

### Frontend
- HTML
- CSS
- JavaScript

### Database
- H2 Database / MySQL
